2. Datos que recogemos

Cuando solicitas una cita recogemos nombre, teléfono, correo electrónico, servicio, fecha y hora seleccionados. El sistema también conserva el estado de la cita y las fechas técnicas de creación o cancelación.

3. Finalidad y base jurídica

Usamos estos datos para gestionar, confirmar y administrar citas. La base jurídica es la aplicación de medidas precontractuales o la ejecución del servicio solicitado. No usamos estos datos para publicidad ni elaboramos perfiles.

4. Destinatarios y conservación

Los datos pueden ser tratados por proveedores técnicos necesarios para prestar el servicio, como el hosting y Supabase, que actúan según la configuración contratada por el responsable. Se conservarán durante el tiempo necesario para gestionar la cita y atender obligaciones legales; el responsable debe concretar los plazos antes de publicar.

5. Derechos

Puedes solicitar acceso, rectificación, supresión, oposición, limitación del tratamiento y portabilidad escribiendo a [EMAIL DE PRIVACIDAD]. También puedes reclamar ante la Agencia Española de Protección de Datos (AEPD).

6. Seguridad

Aplicamos medidas técnicas razonables para proteger la información. No introduzcas datos especialmente sensibles en el formulario de reserva.

7. Cambios

Esta política puede actualizarse para reflejar cambios legales, técnicos o del servicio. La fecha de actualización debe indicarse antes de publicar.
